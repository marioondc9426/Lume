# Versions

English translation of [CHANGELOG.md](CHANGELOG.md) (the Portuguese one is the original).

How versions are numbered:
- **1.1, 1.2, 1.3...** = a new version with new features (the number after the dot goes up).
- **1.1.01, 1.1.02...** = fixes (patches) for version 1.1, no new features.
- The number lives in `VERSION` at the top of `app.py` and shows in Settings > Updates.
- Every version gets a Git tag (`v1.0`, `v1.1.01`...).
